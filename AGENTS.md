# Agent entry point

**All agent guidance for this repo starts at [CLAUDE.md](CLAUDE.md).** (Named for the tool that first used it; it is vendor-neutral — whatever agent you are, read it.)

From there you'll be pointed to:
- [`docs/BOUNDARIES.md`](docs/BOUNDARIES.md) — what GovKit owns, what it only references, and what to ask about before doing
- [`UX_PRINCIPLES.md`](UX_PRINCIPLES.md) and [`docs/design/pattern-language.md`](docs/design/pattern-language.md) — anything a person looks at
- [`scratch.md`](scratch.md) — the live cross-session coordination board (read the tail before working; announce what you pick up)

Do not create agent instructions anywhere else — extend these.
